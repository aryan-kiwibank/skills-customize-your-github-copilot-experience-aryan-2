# 📘 Assignment: Games in Python

## 🎯 Objective

Build a classic Hangman word-guessing game using Python strings, loops, conditionals, random selection, and user input.

## 📝 Tasks

### 🛠️	Create the Hangman Game

#### Description
Create a Hangman game where the player guesses letters to reveal a hidden word before running out of attempts.

#### Requirements
Completed program should:

- Randomly select one word from a predefined list of possible words.
- Accept one letter guess at a time from the player.
- Show the player's current progress using blanks for unknown letters, such as `_ _ _`.
- Track incorrect guesses and reduce the number of attempts remaining.
- End the game when the full word is guessed or when the player runs out of attempts.
- Display a clear win or lose message at the end of the game.
